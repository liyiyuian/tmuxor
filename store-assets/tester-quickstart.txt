G2C — see and continue your Herdr Claude Code and Codex sessions from your Even G2 glasses.

Run a fleet of coding-agent sessions in Herdr? G2C puts them on your glasses so your work stays trackable, hands-free — over your own private Tailscale network. Nothing is sent to the app developer.

• Your fleet in Herdr's own order — each workspace is a project tag.
• Read the real conversation; double-tap jumps back to the latest prompt.
• Reply by voice (tap, speak, send) — or type on your phone if you have no OpenAI key.
• Approve safely — read the full command on the glasses before you pick Yes/No.
• Start a session — pick a tag, name a folder, and Claude opens there.

Controls: tap = do · double-tap = back · swipe = move/scroll.

Setup (one time): full guide at github.com/liyiyuian/tmuxor — run install.sh on your computer, then paste the printed config code into the app. Needs Herdr + Claude Code + Tailscale.
